# tree-sitter-query

[![CI](https://github.com/konomanoasa/tree-sitter-query/actions/workflows/ci.yaml/badge.svg)](https://github.com/konomanoasa/tree-sitter-query/actions/workflows/ci.yaml)

[![npm](https://img.shields.io/npm/v/@konomanoasa/tree-sitter-query)](https://www.npmjs.com/package/@konomanoasa/tree-sitter-query)

[Tree-sitter](https://tree-sitter.github.io/tree-sitter/) grammar for
Tree-sitter Query Language.

## Installation

```sh
npm install @konomanoasa/tree-sitter-query
```

## Development

Development uses Node.js 24.21.0 or later.

```sh
npm install
npm run build
npm test
```
